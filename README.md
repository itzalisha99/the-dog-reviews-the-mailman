One funny one-line review that a dog gives the mailman, written by `main.py` to `/output/entry.txt`.

> One star. He delivers to my house every day and still acts surprised to see me. I live here. I have always lived here.

Run it with `python3 main.py`. The entry is 118 characters, inside the 1–200 character gate, and `main.py` re-reads the file it wrote to verify the bytes match.
